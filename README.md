# Dawnside Academy

A responsive, front-end school CRM dashboard for managing an online learning community. Built with plain HTML, CSS, and JavaScript—no build step or dependencies required.

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static web server. The Google Fonts link is optional; the interface has system fallbacks.

## Included

- Overview dashboard with enrollment, course, completion, and revenue metrics
- Student directory with live search, status filters, and an add-student invitation form
- Course catalog cards, messaging inbox, analytics summary, calendar and settings placeholders
- Responsive sidebar and layouts for mobile and desktop
- Sample content is held in browser memory and resets on page reload; connect an API and persistent database to make it production-ready

This is a front-end prototype. Authentication, server-side data, payment processing, and email delivery are not included.
